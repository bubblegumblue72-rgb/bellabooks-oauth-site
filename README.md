# BellaBooks OAuth Site

Public information site for **BellaBooks Live Monitors**, the OAuth identity used by the private Bella Books automation system.

This repository intentionally contains **no private Bella Books credentials, OAuth tokens, service-account keys, workbook exports, vendor credentials or production source code**.

Pages:
- Homepage
- Privacy Policy
- Terms of Service

Deployment target: GitHub Pages, then a separately registered compliant custom domain.
