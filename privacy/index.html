BellaBooks Live Monitors

Privacy Policy

This policy explains how the private Bella Books automation system uses Google account and operational data.

1. Scope

BellaBooks Live Monitors is the OAuth identity used by the privately operated Bella Books business automation system. It is not a public consumer service and does not provide public user registration.

2. Google data accessed

Depending on the active Bella Books function, the system may access:

  • Google Sheets data in Bella Books workbooks.
  • Google Apps Script project source and project metadata.
  • Apps Script deployment, execution/process and metrics information.
  • Cloud Logging entries used for operational diagnostics and audit evidence.
  • Gmail send capability for owner-authorized Bella Books operational notifications.

3. Purpose of access

Google data is used only to operate, monitor, test, validate and audit Bella Books workflows, including inventory management, metadata enrichment, vendor-price monitoring, alerts, sales preparation and operational reporting.

4. Storage and security

OAuth tokens and private runtime credentials are stored in controlled private runtime locations used by the owner-operated Bella Books environment. Public website files do not contain OAuth tokens, client secrets, service-account private keys or business workbook contents.

Access is separated by function and account where practical, and the system is designed to fail closed when required authority or verification evidence is missing.

5. Sharing and sale of data

Bella Books does not sell Google user data. Google user data is not used for advertising. Data is not shared with unrelated third parties. Processing may involve Google services and infrastructure providers only as necessary to operate the authorized system.

6. Data retention and deletion

Operational records are retained only as required for Bella Books operations, audit evidence, troubleshooting and legal/business recordkeeping. OAuth access can be revoked from the relevant Google account at any time. Private runtime tokens can also be deleted locally when access is no longer required.

7. Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable.

8. Contact

Questions about this policy or Bella Books Google-data access can be sent to bubblegumblue72@gmail.com.
