BellaBooks Live Monitors

Official OAuth information site for the owner-operated Bella Books inventory, pricing, monitoring and business automation system.

What Bella Books does

Bella Books uses software automation to support book inventory management, metadata enrichment, vendor-price monitoring, sales preparation, operational reporting and audit evidence.

The system is privately operated and is not offered as a public SaaS product. Google access is used only for authorized Bella Books operational resources and owner-administered accounts.

Google services used

  • Google Sheets for Bella Books workbooks and operational data.
  • Google Apps Script for workbook automation and trigger-based workflows.
  • Gmail API for owner-authorized operational notifications.
  • Cloud Logging for read-only operational diagnostics and audit evidence.

Access is limited to the scopes required for the active Bella Books function. Read-only scopes are preferred when write access is not required.
